Meta 发布首个前沿模型 Muse Wonder：对标 GPT-6 Astra，主打"主动记忆"

PYMNTS · 2026-10-12 · 头版编译

Meta 终于有了自己的前沿模型。10 月 12 日，Meta 超级智能实验室发布 Muse Wonder 与 Muse Wonder Full——公司成立以来首次真正跻身前沿模型行列，定价直接对标 OpenAI 与 Anthropic 的旗舰产品，连"开源优先"的旧路线也一并翻篇。

根据 Meta 当天发布的新闻稿，Muse Wonder 即日起通过 Meta Model API 向开发者开放，同时登陆 Muse Code；Muse Wonder Full 则仅限 Muse Code 订阅用户使用。此外，Wonder 未来将驱动 Meta 个人智能体 Muse 的更多能力。

这对组合延续了今年 4 月发布的 Muse Spark——后者是轻量高速模型，为低延迟调优，是 Meta"个人超级智能"路线图的第一步。Wonder 则走向另一个极端：更大、相对更慢，但在基准测试中得分更高，能处理 Spark 力有不逮的复杂代码任务。

Meta 在模型卡中称，Wonder 与 Wonder Full 的内部测试成绩与 Fable 5.1、GPT-6 Astra 处于同一档。定价同样"前沿"：Wonder API 输入 4 美元/百万 token、输出 20 美元/百万 token，接近 GPT-6 Sol 或 Opus 5.5 的水平。有评论一针见血：Meta 花了两年强调开源路线，如今这个定价说明那个时代结束了——这组数字更接近 GPT-4 级别的定价，而非 Llama 曾经的免费姿态。

能力上，Meta 主打两张牌。"主动记忆"（Active Memory）让模型记住历史对话中的相关细节；"主动专注"（Active Focus）让它在面对难题时尝试其他思路、从错误中恢复、主动追问澄清。Meta 在新闻稿中写道："无论是处理保险理赔、理解租赁合同，还是梳理个人财务，模型都必须读懂眼前的信息并一步步解决问题。"新模型把这种能力带进了法律、金融、健康等专家领域，同时保持前沿级的代码能力，"从做一款游戏到为新公司开发应用"都能覆盖。

安全方面，Meta 称两款模型按"Meta 超级智能扩展框架"训练、评估与发布：被训练为未经许可不分享个人信息，并拒绝协助有害行为。

背景是 Meta 正在为 AI 豪赌加码：9 月 8 日发布个人智能体 Muse（由 Muse Spark 驱动）；花旗分析师 10 月初指出，Muse 正成为"互联网的前门"，到 2030 年可能带来超 270 亿美元收入，是 Meta AI 战略的中心；公司在 AI 基建与人才上的投入已达数十亿美元量级，图像模型 Muse Image 也在路上。

值得玩味的是发布策略：Meta 没有把 Wonder 做成独立产品，而是捆绑进 Muse Code，用 API 让开发者"亲自验证"基准宣称，而非只看新闻稿里的图表。至于与谷歌 Gemini 4 Argon 的对比——那款模型的能力外界仍在摸索中，暂时难下定论。前沿模型的牌桌上，Meta 终于坐了下来。
