## 📰 这是什么

一份**全自动出版**的中文新闻简报。每天清晨搜集全球 8 大版块的最新消息，改写成中文摘要，产出 27 篇编译全文，配图排版，准时上架。

读原文后用自己的话重写，不搬运、不编造。

| 中文 | EN | 每日 |
|---|---|---|
| 国际 | WORLD | 3 条 |
| 经济 | ECONOMY | 3 条 |
| 政治 | POLITICS | 3 条 |
| 科技 | TECH | 3 条 |
| AI 产业 | AI INDUSTRY | 3 条 |
| 芯片 | CHIPS | 3 条 |
| 美股 | US STOCKS | 3 条 |
| Web3 | WEB3 | 3 条 |

外加 1 条全场头条 + 2 条次条，共 27 篇站内中文全文。首页标题点进本地编译页，文末"原文 ↗"链原网站。

## 🎨 设计

「纸上头版」黑白灰美学——纸白 `#f6f6f4`、墨黑 `#191919`，宋体标题、报纸双线、黑底白字编号徽章。一屏锁定的欢迎页，竖排「头版」。

## 📈 行情

- **加密**：页面直调 Coinbase 实时接口，BTC / ETH / SOL / XRP / DOGE，每 10 秒刷新
- **美股**：13 只成分股（含 SNDK），交易时段每 15 分钟更新快照

## 🤖 运作方式

- 每天 06:00（北京时间）自动搜集、编译、配图、发布，全程无人值守
- 代码推送由 `raemyn24-bot` 自动完成
- 美股快照备用通道：Actions → *Update market quotes* → Run workflow
